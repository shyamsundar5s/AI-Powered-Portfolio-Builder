# AI-Powered-Portfolio-Builder
The **AI-Powered Portfolio Builder** is a full-stack application that helps users create professional portfolios effortlessly. By leveraging OpenAI's capabilities, the app generates tailored portfolio content based on user inputs. It also provides customizable templates, analytics, and SEO-ready portfolio outputs.
## Features
1. **AI-Generated Content**:
   - Uses OpenAI API to generate personalized portfolio content (e.g., summaries, project descriptions).
2. **Intuitive Form**:
   - Multi-step React form for easy data entry (e.g., name, skills, projects, bio).
3. **PDF Export**:
   - Export portfolios as professional, well-designed PDF files.
4. **Authentication**:
   - Full-stack authentication with options for email/password and third-party OAuth (Google, GitHub).
5. **Hosting**:
   - Hosted portfolios with custom URLs for easy sharing.
